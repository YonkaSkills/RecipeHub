# Technical Design Document (TDD)

## Tech Stack
- Frontend: React.js
- Backend: Node.js + Express
- Database: MySQL
- Authentication: JWT

## API Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/auth/register | Register User |
| POST | /api/auth/login | Login User |
| GET | /api/recipes | Get Recipes |

## Database Tables
- User
- Recipe
- MealPlan
- ShoppingList

## Deployment
- Frontend: Vercel
- Backend: Render
- Database: Railway
