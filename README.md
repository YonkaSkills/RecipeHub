# 🍳 Recipe/Meal Organizer

A simple and smart **Recipe/Meal Organizer** that helps users save, organize, and manage their favorite recipes in one place. Users can categorize recipes based on meal types or dietary preferences and generate a **weekly shopping list** based on their selected recipes.

## 📌 Features

* 🍽️ **Save Recipes** – Store favorite recipes for easy access.
* 🗂️ **Categorize Recipes** – Organize recipes into categories such as:
  * Breakfast
  * Lunch
  * Dinner
  * Vegan
  * Vegetarian
  * Desserts
* 🔍 **Search Recipes** – Quickly find recipes by name or category.
* 📅 **Meal Planning** – Select recipes for different days of the week.
* 🛒 **Shopping List Generator** – Automatically generate a shopping list based on ingredients required for selected recipes.
* ✏️ **Recipe Management** – Add, edit, and delete recipes.
* 📱 **User-Friendly Interface** – Simple and easy-to-use design.

## 🛠️ Technologies Used

* **Frontend:** React.js
* **Styling:** CSS
* **Backend/Database:** Supabase
* **Authentication:** Supabase Authentication
* **Database:** Supabase PostgreSQL

## ⚙️ How It Works

1. **Add or Save Recipes**

   * Users can add recipes with ingredients, instructions, category, and other details.

2. **Organize Recipes**

   * Recipes can be grouped into categories such as Breakfast, Vegan, Dinner, or Desserts.

3. **Plan Meals**

   * Users select recipes they want to prepare during the week.

4. **Generate Shopping List**

   * The system collects ingredients from the selected recipes.
   * Required ingredients are combined into a single weekly shopping list.

5. **Manage Recipes**

   * Users can update recipe details or remove recipes whenever required.


## 🚀 Installation

### 1. Clone the Repository
git clone <your-repository-url>
### 2. Navigate to the Project
cd Recipe-Meal-Organizer
### 3. Install Dependencies
npm install
### 4. Start the Development Server
npm run dev
The application will run on the local development server.
